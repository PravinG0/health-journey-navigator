# Health Journey Navigator

Create ONLY the next homepage section immediately after the “Optimal Health Starts With Balance” section for Royal Medical Center.

Do not modify the hero section or the previous “Optimal Health Starts With Balance” section.

SECTION CONCEPT

Introduce Royal Medical Center’s core treatment programs through a premium, interactive “Find Your Path to Better Health” section.

The purpose of this section is to help visitors quickly understand the main programs available and choose the area that is relevant to them.

SECTION EYEBROW

PERSONALIZED PROGRAMS

HEADLINE

A Personalized Path to Better Health

DESCRIPTION

Explore personalized programs designed to support your individual health goals, from hormone balance and weight management to peptide therapy.

PROGRAMS

Create four visually premium program experiences:

01 — TRT FOR MEN

Testosterone Replacement Therapy

Support energy, mental clarity, confidence, and overall well-being through personalized testosterone therapy.

CTA:

Explore TRT →

02 — HRT FOR WOMEN

Women's Hormone Therapy

Personalized hormone programs designed around individual needs and hormonal balance.

CTA:

Explore HRT →

03 — WEIGHT LOSS

Medical Weight Management

Personalized medical programs designed to help men and women achieve lasting weight-management goals.

CTA:

Explore Weight Loss →

04 — PEPTIDE THERAPY

Peptide Therapy

Explore medically guided peptide treatments designed around your individual wellness goals.

CTA:

Explore Peptides →

Use the supplied Royal Medical Center content as the source for these program descriptions. Do not invent additional medical claims.

VISUAL DESIGN

Do NOT create four ordinary rectangular cards.

Create a large interactive program showcase.

Use a horizontal 4-item navigation on desktop:

TRT FOR MEN | HRT FOR WOMEN | WEIGHT LOSS | PEPTIDES

Below it, display one large active program panel.

The active panel should contain:

Program number

Program title

Short description

CTA

Premium lifestyle visual

Subtle decorative SVG graphics

When the user hovers or clicks another program, transition the active panel smoothly.

INTERACTION

Make the program selector feel premium and interactive.

When selecting a program:

Active navigation item gets an accent underline

Large content panel transitions smoothly

Image changes with a soft fade/slide

Decorative SVG elements animate

Program number changes

CTA updates

Use smooth transitions around 500–700ms.

Do not use aggressive animations.

VISUAL STYLE

Use premium healthcare/wellness imagery.

Avoid:

Hospitals

Medical equipment

Doctors with stethoscopes

Generic healthcare stock imagery

Prefer lifestyle-oriented imagery that represents:

Energy

Confidence

Wellness

Healthy lifestyle

Personal transformation

Keep imagery sophisticated and natural.

SVG DETAILS

Add subtle animated SVG elements around the active program visual.

Examples:

Thin orbit lines

Small circles

Organic curves

Subtle particles

Gradient rings

The SVG animation should change slightly based on the selected program.

Keep it elegant and minimal.

LAYOUT

Desktop

Use:

Top:
Eyebrow + headline + description

Middle:
4 program navigation items

Bottom:
Large split showcase panel

Approximately:

45% content / 55% visual

Give the section generous whitespace.

MOBILE

On mobile:

Stack the program navigation vertically or convert it into a horizontally scrollable selector.

Show one program at a time.

Use:

Program selector

Image

Program number

Title

Description

CTA

Make sure the cards do not become excessively tall.

DESIGN LANGUAGE

Continue the same design language from the previous sections:

Premium wellness
+
Modern healthcare
+
Personalized treatment
+
Subtle futuristic technology

Use:

Large typography

Clean whitespace

Soft gradients

Organic shapes

Rounded corners

Thin borders

Subtle shadows

Elegant SVG animation

Do not make this section look like a generic WordPress service grid.

SCROLL ANIMATION

When the section enters the viewport:

Eyebrow fades upward

Headline reveals smoothly

Program navigation appears sequentially

Main showcase panel fades/slides into place

SVG decorations animate subtly

Use lightweight CSS/SVG animations.

Respect prefers-reduced-motion.

ACCESSIBILITY & PERFORMANCE

Use:

Semantic HTML

Proper H2 heading

Accessible buttons

Keyboard-accessible program selection

Strong color contrast

Reduced-motion support

Use CSS transforms and opacity for animations.

Avoid unnecessary animation libraries and heavy effects.

FINAL GOAL

This section should make visitors immediately understand:

“Royal Medical Center has personalized treatment options specifically designed around my needs.”

It should feel like a premium interactive treatment discovery section, not a standard service-card section.
